KeySoft
Company: HumanWare
Category: Operating system or software version history
Versions listed: 11

Overview:
The BrailleNote software suite (word processor, book reader, email, web, planner) from Pulse Data and HumanWare. It ran on Windows CE from 2000, moved to Android on the BrailleNote Touch (2016), and to Windows 11 on the BrailleNote Evolve (2026). KeySoft applications also run on the Monarch.

Version History:

Version 1: 6.2
Released: 2005
Notes: Shipping version on the BrailleNote mPower at launch.

Version 2: 7.5
Released: By 2008
Notes: Last release for BrailleNote and VoiceNote Classic. Build 29 (May 2008) added 802.11g Wi-Fi card support (Ambicom WL54G, USR5421), fixed appointment scheduling, fixed USB and CD-ROM devices being identified as printers, and fixed spell-check word retention.

Version 3: 8.0
Released: Announced January 2009; released July 2009
Notes: For mPower and PK only, not Classic. Added real-time communication features, a richer book-reading experience and a 90-day Sendero GPS trial. Required one SMA count; free for units bought after January 1, 2009. mPower releases stopped at 8.1.

Version 4: 9.1
Released: Date not given in the sources cited for this history
Notes: For the Apex. Enhanced tables and formatting support.

Version 5: 9.3
Released: Previewed March 31, 2012
Notes: For the Apex. Bluetooth file transfer, opening Word 2007/2010 and OpenOffice documents, saving to online services such as Google Docs, and third-party development tools with a BrailleNote simulator.

Version 6: 9.4.1
Released: 2014
Notes: For the Apex. Added KeyMaps, a free virtual navigation and map-exploration tool.

Version 7: KeySoft for Android
Released: 2016
Notes: On BrailleNote Touch (Android 4.4).

Version 8: Touch Plus (Android 8.1)
Released: February 2019
Notes: BrailleNote Touch Plus ships with Android 8.1.

Version 9: KeySoft Lite
Released: February 2021
Notes: On the Brailliant BI 20X and BI 40X displays.

Version 10: Touch Plus update
Released: September 2025
Notes: KeyMath renamed KeyGraph; KeyRecorder added (user reports). Still Android 8.1.

Version 11: KeySoft on Windows 11
Released: 2026
Notes: On BrailleNote Evolve, alongside a customized NVDA.
