System Access milestones
Company: Serotek (now Pneuma Solutions)
Category: Operating system or software version history
Versions listed: 4

Overview:
Serotek's and Pneuma Solutions' System Access screen reader. Per-version release notes were not found.

Version History:

Version 1: FreedomBox
Released: Date not given in the sources cited for this history
Notes: Serotek's FreedomBox was a simplified, speech-driven portal for the web, email and other services; AccessWorld reviewed it as a system for 'the liberty to use a computer'. It evolved into System Access in 2005.

Version 2: System Access
Released: 2005
Notes: Full screen reader access to Word, Excel, Outlook Express, Internet Explorer and PowerPoint text.

Version 3: System Access to Go
Released: 2007 (free from February 2008)
Notes: Launched in 2007 as a web-based screen reader that needs no install. From 2008 it was free through the AIR Foundation (Accessibility Is a Right). It ran from a website on any compatible PC: web, email, forms, PDF and operating-system tasks.

Version 4: Pneuma Solutions
Released: 2020
Notes: Mike Calvo and Matt Campbell co-founded Pneuma Solutions.

Devices and Software That Ran It:
System Access (Serotek (now Pneuma Solutions), December 2005)

System Requirements:
System Access to Go (2008): Windows XP or Vista, an Internet connection, a sound card and a recent Internet Explorer.
Other versions: not listed in the sources cited (System Access release notes were not found).
