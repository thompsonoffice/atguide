Mobile Speak
Company: Code Factory
Category: Screen Readers
Released: 2004 (Symbian); 2005 (Pocket PC); 2006 (Smartphone)

Overview:
The first screen reader to support both Symbian and Windows Mobile. It handled calls, SMS, email, web browsing and more.

Specs:
Developer: Code Factory
Release years: 2004 (Symbian); 2005 (Pocket PC); 2006 (Smartphone)
Runs on: Symbian S60, Windows Mobile
Default speech: Fonix DECtalk (among others)
Price: Not documented
Voices: DECtalk Perfect Paul

History:
Launched for Symbian in 20 countries in 2004. Code Factory called the 2005 Pocket PC version the first touch-based screen reader, and Smartphone support followed in 2006. AFB tested version 2.8 in 2006 and Mobile Speak Smartphone 1.2. It used Fonix DECtalk. It became obsolete as Symbian ended.
