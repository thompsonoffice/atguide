Mobile Speak
Company: Code Factory
Category: Screen Readers
Released: 2004 (Symbian); 2005 (Pocket PC); 2006 (Smartphone)

Overview:
The first screen reader to support both Symbian and Windows Mobile. It handled calls, SMS, email, web browsing and more.

History:
Launched for Symbian in 20 countries in 2004. Code Factory called the 2005 Pocket PC version the first touch-based screen reader, and Smartphone support followed in 2006. AFB tested version 2.8 in 2006 and Mobile Speak Smartphone 1.2. It used Fonix DECtalk. It became obsolete as Symbian ended. Code Factory, founded in 1998 near Barcelona, Spain, by Eduard Sánchez, first made games for the blind and in 2003 released Mobile Accessibility, a simpler talking phone interface. Mobile Speak was announced in April 2004 with Acapela's PocketBabil synthesizer for Nokia Series 60 phones and the Siemens SX1. AccessWorld's 2004 review of version 1.0 found it used Eloquence and cost $295 in the US through Optelec. Code Factory says it launched in 20 countries. Pocket PC support came in 2005 and Windows Mobile Smartphone support in 2006, when Vodafone began offering it. Nokia partnered with Code Factory in 2007, it won an AFB Access Award in 2008, and in 2011 Code Factory supplied Nokia with a branded version called Nokia Screen Reader, while moving to Android with Mobile Accessibility.
