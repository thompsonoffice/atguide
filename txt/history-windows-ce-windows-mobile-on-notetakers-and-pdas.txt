Windows CE / Windows Mobile (on notetakers and PDAs)
Company: Microsoft
Category: Operating system or software version history
Versions listed: 8

Overview:
Microsoft's embedded operating system, used under most notetakers from 2000 to the mid-2010s.

Version History:

Version 1: CE 2.12 to CE.NET 4.2
Released: 2000 onward
Notes: BrailleNote Classic.

Version 2: CE.NET 4.1
Released: 2003
Notes: ALVA MPO 5500.

Version 3: CE.NET 4.2 / Pocket PC 2003
Released: 2003
Notes: PAC Mate BX400/QX400.

Version 4: CE.NET
Released: 2004
Notes: BrailleSense (Classic).

Version 5: CE.NET 5.0
Released: 2007
Notes: VoiceSense.

Version 6: CE 5.0
Released: 2008 to 2012
Notes: BrailleSense Plus, OnHand, Braille EDGE.

Version 7: Windows Mobile 6
Released: 2007
Notes: PAC Mate Omni.

Version 8: CE 6
Released: 2009 onward
Notes: BrailleNote Apex, BrailleSense U2 and U2 QWERTY, QBraille XL.
