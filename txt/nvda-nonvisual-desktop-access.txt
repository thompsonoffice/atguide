NVDA (NonVisual Desktop Access)
Company: NV Access
Category: Screen Readers
Released: 2006 (version 0.5 in 2007) to present

Overview:
A free, open-source Windows screen reader written in Python and C++, available in 62 languages.

Specs:
Developer: NV Access
Release years: 2006 (version 0.5 in 2007) to present
Runs on: Windows 10 (22H2 or later) and 11, 64-bit; Server 2016 to 2025
Default speech: eSpeak NG on Windows 7/8; Windows OneCore voices by default on Windows 10 and later (since NVDA 2019.3)
Price: Free

Physical Description:
Not applicable (software)

Features:
Not documented

History:
Michael Curran began it in April 2006, motivated by the cost of commercial screen readers, and named it NVDA late that year. Version 0.5 came in 2007, and the 0.6 releases (2008 to 2009) added better web browsing, braille output and more languages. NV Access was founded in 2007. NVDA releases about four times a year; 2026.2 came out on August 31, 2026 and 2026.3 is current.
