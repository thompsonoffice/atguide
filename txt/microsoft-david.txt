Microsoft David
Company: Microsoft
Category: TTS Voices
Released: Windows 8 (2012) to present

Overview:
A US English male voice.

Specs:
Maker: Microsoft
First released: Windows 8 (2012) to present
Synthesis type: Microsoft does not publish the technique. Microsoft lists this as a standard Windows TTS voice, which Windows 11 calls a 'legacy voice', as distinct from the newer neural 'natural voices'.
Platforms: Windows 8, 8.1, 10 and 11
Default on or shipped with: Windows 8 and later (US English)
Price: Not documented
Shipped with or used by: Microsoft Narrator

Physical Description:
Not applicable (software)

Features:
Not documented

History:
Introduced with Windows 8. It remains in Windows 10 and 11 and is listed as a Narrator voice.
Predecessors: Microsoft Anna (Microsoft, Windows Vista (2007) and Windows 7)

Not applicable (software)

Windows 8, 8.1, 10 and 11
