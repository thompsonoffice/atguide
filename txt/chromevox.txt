ChromeVox
Company: Google
Category: Screen Readers
Released: May 2011 (developer beta) to present

Overview:
The built-in screen reader for Chrome OS, originally built as a Chrome extension using only web technologies.

History:
Unveiled at Google I/O 2011 by T. V. Raman's team as an early developer beta. It used experimental TTS and accessibility extension APIs and exposed an API for web developers. T.V. Raman announced the developer beta, which used Chrome's experimental tts and accessibility extension APIs and offered web developers a simple screen reader API. Over time it moved from a separate extension into the operating system, and its code now lives in the Chromium tree. Google rebuilt it from the ground up as ChromeVox Next, which became the default on all Chromebooks with Chrome 56 at the end of January 2017. Next changed the modifier from Shift+Search to Search alone and added a ChromeVox panel with menus, braille captions and navigation from USB braille display keyboards.
