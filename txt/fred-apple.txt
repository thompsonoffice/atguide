Fred (Apple)
Company: Apple
Category: TTS Voices
Released: MacinTalk 3 (1994) to Mac OS X

Overview:
A classic male Mac voice, age 30 in its voice resource.

Specs:
Maker: Apple
First released: MacinTalk 3 (1994) to Mac OS X
Synthesis type: MacinTalk 3 engine
Platforms: System 7 to Mac OS X
Default on or shipped with: Not the system default (Alex is the default from Mac OS X 10.5)
Price: Not documented
Shipped with or used by: MacinTalk 3

Physical Description:
Not applicable (software)

Features:
Not documented

History:
In 1994 it shipped with Speech Manager 1.2.1, which 'includes Fred's voice', and it was first among the MacinTalk 3 voices. Its stored phrase: 'I sure like being inside this fancy computer.' It survived byte-identical into Mac OS X.
