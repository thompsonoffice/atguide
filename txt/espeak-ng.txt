eSpeak NG
Company: eSpeak / eSpeak NG project
Category: TTS Voices
Released: Late 2015 to present

Overview:
The maintained fork of eSpeak, supporting over 100 languages. It can use Klatt synthesis or MBROLA voices.

Specs:
Maker: eSpeak / eSpeak NG project
First released: Late 2015 to present
Synthesis type: Formant (optionally Klatt or MBROLA)
Platforms: Linux, Windows, Android and others
Default on or shipped with: Fenrir generic speech driver; optional on Victor Reader Stream 3
Price: Not documented
Shipped with or used by: Victor Reader Stream (3rd generation); Fenrir

History:
Forked officially in late 2015 from Reece H. Dunn's GitHub maintenance branch (from 2010). In August 2024, version 1.52-dev supported 137 languages. HumanWare added it to the Stream 3 in firmware 1.7 (September 2026). Fenrir's default generic speech driver calls espeak or espeak-ng. Reece Dunn forked eSpeak on GitHub on June 25, 2010 (from release 1.43.46), at first to make it easier to build on Linux and other POSIX systems. After Jonathan Duddington had been inactive for eight months, the espeak-ng fork was started on December 11, 2015, and its first release, 1.49.0, came out on September 10, 2016. Because it is small and covers many languages, eSpeak NG ships with the NVDA screen reader and with Android, Ubuntu and other Linux distributions.
Predecessors: eSpeak (eSpeak / eSpeak NG project, 2007 (origins 1995))
