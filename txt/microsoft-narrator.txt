History:
Debuted in Windows 2000, speaking with Microsoft Sam. It gained braille support in 2017, and the Windows 10 Creators Update changed its toggle to Ctrl+Windows+Enter. Windows 10 and 11 voices include David, Zira, Mark and Hazel. Narrator was developed by Professor Paul Blenkhorn in 2000. It made Windows 2000 the first Microsoft operating system with some access for blind people built in, so a blind person could use any such computer right away. The Windows 2000 version used SAPI 4 and could use other SAPI 4 voices. The Windows XP version used SAPI 5 but only the default voice, Microsoft Sam. Vista and 7 moved it to SAPI 5.3 and the Anna voice. Windows 10 offered it in many languages with voices including David, Zira and Mark. Windows 11 redesigned it and added natural voices. Windows Phone had a simpler version.
