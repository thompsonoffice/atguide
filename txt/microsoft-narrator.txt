Microsoft Narrator
Company: Microsoft
Category: Screen Readers
Released: February 17, 2000 to present

Overview:
The screen reader built into Windows.

Specs:
Developer: Microsoft
Release years: February 17, 2000 to present
Runs on: Windows 2000 and later
Default speech: Not documented
Price: Not documented
Voices: Microsoft Sam; Microsoft David; Microsoft Zira; Microsoft Mark; Microsoft Hazel

Physical Description:
Not applicable (software)

Features:
Not documented

History:
Debuted in Windows 2000, speaking with Microsoft Sam. It gained braille support in 2017, and the Windows 10 Creators Update changed its toggle to Ctrl+Windows+Enter. Windows 10 and 11 voices include David, Zira, Mark and Hazel.

Ports:
Not applicable (software)

Operating System:
Windows 2000 and later
Operating system history: Narrator versions

System Requirements:
Included with Windows 2000 and later; no separate requirements documented
