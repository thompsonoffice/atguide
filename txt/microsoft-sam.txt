Microsoft Sam
Company: Microsoft
Category: TTS Voices
Released: 2000 (Windows 2000) to Windows XP

Overview:
The default English male voice of Windows 2000 and XP, used by Narrator.

Specs:
Maker: Microsoft
First released: 2000 (Windows 2000) to Windows XP
Synthesis type: Concatenative (Microsoft Research Whistler engine with unit selection and LPC vocoder)
Platforms: Windows 2000 and XP (SAPI 4 and 5)
Default on or shipped with: Windows 2000 and XP; Narrator
Price: Not documented
Shipped with or used by: Microsoft Narrator

Physical Description:
Not applicable (software)

Features:
Not documented

History:
Released in SAPI 4 and SAPI 5 versions, which differ in pronunciation. Windows Vista and 7 replaced it with Microsoft Anna. The SAPI 5 version can still be installed on later Windows through the SAPI 5.1 SDK. SAPI 4 versions of Sam, Mike and Mary (SAPI 4.0 dates from 1998) and SAPI 5 versions (SAPI 5.1 shipped with Windows XP) differ in speech patterns, pronunciation and some words. Sam's SAPI 5 version has a known 'soy/soi' glitch. Redistributable SAPI 4 versions were offered for Windows 9x but are no longer on Microsoft's site; programs such as Speakonia and TTSReader still run them on XP, Vista and later. Microsoft's 2006 Vista article had Sam say 'Anna will make me redundant'. Windows Vista and 7 shipped no male voice.
Successors: Microsoft Anna (Microsoft, Windows Vista (2007) and Windows 7)
