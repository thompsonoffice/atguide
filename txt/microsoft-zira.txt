Microsoft Zira
Company: Microsoft
Category: TTS Voices
Released: Windows 8 to present

Overview:
A US English female voice.

Specs:
Maker: Microsoft
First released: Windows 8 to present
Synthesis type: Microsoft does not publish the technique. Microsoft lists this as a standard Windows TTS voice, which Windows 11 calls a 'legacy voice', as distinct from the newer neural 'natural voices'.
Platforms: Windows 8 and later
Default on or shipped with: Windows 8 and later
Price: Not documented
Shipped with or used by: Microsoft Narrator
