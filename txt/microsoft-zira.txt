Microsoft Zira
Company: Microsoft
Category: TTS Voices
Released: Windows 8 to present

Overview:
A US English female voice.

Specs:
Maker: Microsoft
First released: Windows 8 to present
Synthesis type: Microsoft does not publish the technique. Microsoft lists this as a standard Windows TTS voice, which Windows 11 calls a 'legacy voice', as distinct from the newer neural 'natural voices'.
Platforms: Windows 8 and later
Default on or shipped with: Windows 8 and later
Price: Not documented
Shipped with or used by: Microsoft Narrator

Physical Description:
Not applicable (software)

Features:
Not documented

History:
Introduced with Windows 8 and still a Narrator voice in Windows 10 and 11. Zira (U.S. female) arrived with David and Hazel in Windows 8. In Windows 10, Microsoft's mobile voices Mark and Zira, the same as on Windows Phone 8, 8.1 and Windows 10 Mobile, became available on the desktop. Windows 11 reclassed the Windows 10 voices as 'legacy voices' and added Azure 'natural voices' (Aria, Jenny and Guy) for Narrator starting with version 22H2.
Predecessors: Microsoft Anna (Microsoft, Windows Vista (2007) and Windows 7)
