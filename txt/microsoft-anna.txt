Microsoft Anna
Company: Microsoft
Category: TTS Voices
Released: Windows Vista (2007) and Windows 7

Overview:
A SAPI 5-only female voice designed to sound more natural than Sam. It was the default English voice in Vista and Windows 7.

Specs:
Maker: Microsoft
First released: Windows Vista (2007) and Windows 7
Synthesis type: Concatenative: selects and splices segments from hours of recorded speech (Microsoft, 2006)
Platforms: Windows Vista and 7 (SAPI 5.3)
Default on or shipped with: Windows Vista and Windows 7
Price: Not documented

Not applicable (software)

Features:

History:
Microsoft Streets & Trips 2006 and later installed it on Windows XP. Vista and 7 shipped no male voice. Anna became the default English voice in Windows Vista and Windows 7. She is a SAPI 5-only voice designed to sound more natural than Microsoft Sam, and Microsoft Streets & Trips 2006 and later installed her on Windows XP for spoken directions. No male voice shipped with Vista or 7. Windows 8 brought David, Zira and Hazel as more natural-sounding successors.
Predecessors: Microsoft Sam (Microsoft, 2000 (Windows 2000) to Windows XP)
Successors: Microsoft David (Microsoft, Windows 8 (2012) to present); Microsoft Zira (Microsoft, Windows 8 to present)
