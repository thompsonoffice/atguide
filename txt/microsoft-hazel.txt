Microsoft Hazel
Company: Microsoft
Category: TTS Voices
Released: Windows 8 to present

Overview:
A UK English female voice.

Specs:
Maker: Microsoft
First released: Windows 8 to present
Synthesis type: Microsoft does not publish the technique. Microsoft lists this as a standard Windows TTS voice, which Windows 11 calls a 'legacy voice', as distinct from the newer neural 'natural voices'.
Platforms: Windows 8 and later
Default on or shipped with: Windows 8 and later (UK English)
Price: Not documented
Shipped with or used by: Microsoft Narrator

Physical Description:
Not applicable (software)

Features:
Not documented

History:
Introduced with Windows 8 and still a Narrator voice. Hazel (U.K. female) came with David and Zira in Windows 8 as a more natural-sounding voice than Anna. In Windows 10 she was removed from the U.S. English language pack.

Not applicable (software)
